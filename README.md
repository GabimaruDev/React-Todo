<h1>Todo List</h1>

- React, Redux, Typescript
- Drag and Drop Library(DnD kit)

<h2>Functional</h2>

- Adding, editing, deleting, moving tasks
- Showing the number of active tasks
- Change type tasks(all, active, completed)
- Clear completed tasks

<h2>Launch</h2>

```
npm i && npm run start
```
